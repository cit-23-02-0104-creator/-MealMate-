# 🍔 MealMate — Flutter Food Ordering App

A modern food ordering mobile application built with **Flutter and Dart**. This portfolio project demonstrates authentication UI, menu browsing, cart management, checkout, order history, validation and local persistence.

## Features
- Splash screen
- Login & registration validation
- Food categories: Meals, Sides and Snacks
- Add to cart and quantity controls
- Automatic cart total calculation
- Checkout with delivery address
- Payment method selection (demo)
- Place order confirmation
- Persistent order history using SharedPreferences
- Logout
- Material 3 responsive UI

## Tech Stack
- Flutter
- Dart
- Material 3
- SharedPreferences

## Run
```bash
flutter pub get
flutter run
```

## Build APK
```bash
flutter build apk --release
```
